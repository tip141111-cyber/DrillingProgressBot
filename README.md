# DrillingProgressBot

Telegram-бот для ежедневного внесения данных в Excel-таблицу учета отверстий.

## Что делает бот

- по будням в 17:10 задает вопросы по работе, если отчет за день еще не внесен;
- перед вводом предлагает выбрать линейку: `АФУ 1/4`, `АФУ 3` или `Обе линейки`;
- принимает значения за день только по выбранной линейке;
- прибавляет введенные значения к текущим данным в таблице;
- обновляет Excel-файл в `data/uchet_bureniya_otverstiy.xlsx`;
- отправляет актуальную таблицу после заполнения;
- отправляет таблицу по команде `/download`.
- разрешает работу только chat_id из `ADMIN_CHAT_IDS`.

## Команды

- `Записать` - внести данные сейчас;
- `Откорректировать` - вручную поставить точные текущие значения;
- `Скачать актуальную` - скачать актуальную таблицу;
- `Отмена` - отменить текущий ввод;
- `/start` - подключить чат к ежедневному опросу.

`Записать` прибавляет введенные числа к текущим значениям.
`Откорректировать` заменяет текущие значения на введенные вручную.
После выбора действия бот спросит, какую линейку заполнять. Если выбрать только `АФУ 1/4`, значения `АФУ 3` не изменятся.

## Настройка в PyCharm

1. Откройте папку проекта:

   `C:\Users\Alexander\PycharmProjects\DrillingProgressBot`

2. Создайте виртуальное окружение в PyCharm или через терминал:

   ```powershell
   python -m venv .venv
   .\.venv\Scripts\Activate.ps1
   pip install -r requirements.txt
   ```

3. Скопируйте `.env.example` в `.env`.

4. Создайте Telegram-бота через BotFather и вставьте токен:

   ```text
   TELEGRAM_BOT_TOKEN=ваш_токен
   ADMIN_CHAT_IDS=299399554
   BOT_TIMEZONE=Asia/Yakutsk
   BOT_PROMPT_HOUR=17
   BOT_PROMPT_MINUTE=10
   ```

   Если нужен доступ с нескольких аккаунтов или чатов, перечислите ID через запятую:

   ```text
   ADMIN_CHAT_IDS=299399554,123456789
   ```

5. Запустите:

   ```powershell
   python bot.py
   ```

6. Напишите своему боту `/start`.

Если Excel-файл открыт и Windows не даст его перезаписать, бот сохранит обновленную копию в папку `updated` и отправит ее в Telegram.
